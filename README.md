Generator Code Desktop Application

A desktop application built with C# and WinForms that generates CRUD operations and layered architecture code automatically to reduce repetitive development tasks and improve productivity.

Features
Generate CRUD operations
Generate Data Access Layer (DAL)
Generate Business Layer (BLL)
SQL Server integration
Reduce boilerplate code
Improve code organization
Technologies
C#
.NET Framework
WinForms
SQL Server
ADO.NET
Purpose

This project was developed to simplify repetitive coding tasks and speed up desktop application development.
